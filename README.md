# Trae 日志分析工具

一个纯前端的静态网页工具，用于分析 Trae 对话日志并提取工具调用统计信息。

## ✨ 功能特性

- 📊 **统计分析**：自动提取工具调用次数、成功率、状态分布
- � **文本报告**：生成可复制的 ASCII 格式报告，方便分享
- 🎯 **示例加载**：内置示例日志，一键加载演示
- 🚀 **纯前端**：无需后端服务器，直接打开即用
- 🎨 **简洁设计**：2010 年代风格的扁平化设计
- 🌐 **GitHub Pages 友好**：完美支持静态部署

## 📝 日志格式

工具从日志中提取以下格式的内容：
```
toolName: <工具名称>
status: <状态>
```

示例：
```
toolName: edit_file_update
status: success
```
